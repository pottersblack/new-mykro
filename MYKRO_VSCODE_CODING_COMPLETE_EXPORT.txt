# MYKRO ↔ VS Code Copilot Wiring Architecture

## Overview

This document describes the complete wiring that makes MYKRO act as a full 
replacement for GitHub Copilot in VS Code.

**Goal:** One-click setup where users open VS Code and MYKRO provides chat, 
autocomplete, and autonomous coding—all locally.

## Wiring Contract

### 1. VS Code → Extension

**Trigger:** User opens VS Code

**Handler:** `extension.ts:activate()`

**Actions:**
- Read config from `vscode.workspace.getConfiguration('mykro')`
- Initialize `GatewayClient` pointing to `http://127.0.0.1:8090`
- Register `MykroLanguageModelProvider` as vendor `'mykro'`
- Register `MykroInlineCompletionProvider` for all file types
- Create `@mykro.copilot` chat participant
- Set up `BackendManager` for auto-startup

**Config Used:**
```json
{
  "mykro.gatewayUrl": "http://127.0.0.1:8090",
  "mykro.defaultModel": "mykro-auto",
  "mykro.autoStartBackendOnPrompt": true,
  "mykro.inlineCompletionsEnabled": true
}
```

---

### 2. Extension → Gateway (Chat Completions)

**Trigger:** User sends `@mykro your question` or uses chat model selector

**Flow:**
1. **Chat Request Incoming**
   - `vscode.ChatRequest` received by `handleChatRequest()`
   - Command parsed: `plan`, `agent`, `review`, `fix`, or default (`agent`)
   - Workspace root resolved from active editor

2. **Backend Readiness Check**
   - `BackendManager.ensureReady()` called
   - Checks `/health` endpoint
   - If unhealthy and `autoStartBackendOnPrompt=true`:
     - Finds `start-all.ps1` in workspace
     - Spawns PowerShell process to launch gateway + models
     - Waits up to 120s for gateway to be healthy
     - Waits up to 60s for target model to be ready

3. **Message Preparation**
   - Request message converted to `ChatMessage[]`
   - Workspace root injected as context
   - Active file content appended (if referenced)
   - Diagnostic information collected (for `fix` command)

4. **Streaming Request to Gateway**
   - POST to `http://127.0.0.1:8090/v1/chat/completions`
   - Payload:
     ```json
     {
       "model": "mykro-auto",
       "messages": [...],
       "stream": true,
       "mode": "agent",
       "temperature": 0.7,
       "max_tokens": 4096,
       "workspace_root": "/path/to/workspace"
     }
     ```
   - Response: Server-Sent Events (SSE) stream
   - Each chunk yielded to `vscode.Progress`

5. **Fallback to Sync**
   - If streaming fails, falls back to sync POST
   - Single response returned in full

**Error Handling:**
- If gateway is offline and auto-start is disabled → error message shown
- If auto-start times out → user prompted to start manually
- Cancellation token respected throughout

---

### 3. Extension → Gateway (Inline Completions / FIM)

**Trigger:** User types in editor (when `mykro.inlineCompletionsEnabled=true`)

**Flow:**
1. **Code Context Capture**
   - Prefix: previous ~60 lines + current line up to cursor
   - Suffix: current line after cursor + next ~10 lines
   - Debounce: 400ms (configurable)

2. **FIM Request to Gateway**
   - POST to `http://127.0.0.1:8090/v1/completions`
   - Payload:
     ```json
     {
       "model": "mykro-auto",
       "prompt": "<prefix>",
       "suffix": "<suffix>",
       "max_tokens": 128,
       "temperature": 0.2
     }
     ```

3. **Inline Insertion**
   - Response text inserted into editor
   - User can accept/reject with TAB or ESC

---

### 4. Gateway → Model Router

**Trigger:** Gateway receives chat/completion request

**Router Logic (in `model_router.py`):**

1. **Complexity Estimation**
   - Analyze request prompt + system prompt
   - If simple (e.g., "fix typo", FIM) → use `mykro-small` (8081)
   - If complex (e.g., "refactor entire module") → use `mykro-large` (8080)
   - If user explicitly selects → honor user choice

2. **Endpoint Selection**
   - `mykro-auto` → router decides
   - `mykro-large` → always 8080
   - `mykro-small` → always 8081
   - `mykro-mega` → always 8082 (if available)

3. **Forward to Model Server**
   - HTTP POST to selected `llama-server` instance
   - Stream responses back to caller

---

### 5. Gateway → Memory & Context Management

**On Each Request:**

1. **Memory Retrieval**
   - Query `memory_store.py` for relevant memories
   - Rank by keyword overlap + recency
   - Inject up to 1000 chars into system prompt

2. **Context Budgeting**
   - Estimate tokens for conversation history
   - If exceeds budget → trim older messages (keep recent + important)
   - Inject workspace index: file types, key functions, READMEs

3. **Tool Registration**
   - Inject tool descriptions from `tools/` registry
   - Tool names: `read_file`, `write_file`, `execute_command`, `git_status`, etc.

---

### 6. Autonomous Agent (Optional)

**Trigger:** `mykro.autonomousAgentEnabled=true` + workspace idle for 5+ min

**Flow:**
1. `IdleWatcher` detects inactivity
2. `AutonomousSession.start()` invoked
3. Repeatedly calls gateway with `mode: "autonomous"`
4. Agent proposes changes → auto-commits to git
5. User reviews via `git diff`
6. Pauses when user returns to keyboard

## What is MYKRO Copilot?

**MYKRO** is a local AI coding assistant that replaces GitHub Copilot with:

- **Chat** — Ask questions about your code, get refactoring suggestions, generate code
- **Inline Completions** — Get FIM (Fill-In-The-Middle) suggestions as you type
- **Autonomous Agent** — Works during idle periods to improve your codebase
- **Local Execution** — All models run on your machine (no cloud, no API keys)
- **Multi-Model Routing** — Automatically selects small, large, or mega models based on task complexity

---

## Architecture

```
VS Code              Extension           Gateway            Models
┌────────┐           ┌──────────┐       ┌──────────┐      ┌──────┐
│ @mykro │ ────────► │ LM API   │ ────► │ Router   │ ───► │Small │
│ Chat   │           │ Provider │       └──────────┘      └──────┘
└────────┘           │          │              │
                     │ Inline   │              ├────► Large Model
                     │ Complete │              │
                     │ Provider │              └────► Mega (Mixtral)
                     └──────────┘
```

**Key Components:**

1. **VS Code Extension** (vscode-extension/) — Provides chat participant, inline completions, and model selection
2. **MYKRO Gateway** (gui_flask/gateway.py) — Routes requests to models, manages memory, tracks context
3. **Model Servers** — Local llama-server instances running different Qwen and Mixtral models
4. **Config** (gui_flask/config.json) — Defines servers, ports, and settings

## Installation

### Prerequisites

- Windows 10/11 (Linux/Mac support coming)
- VS Code ≥ 1.104.0
- Python 3.10+
- ~20GB free disk space (for models)
- llama.cpp (installed via winget during setup)

1. **Verify you're in the mykro workspace:**
   ```powershell
   cd the repository root
   ```

2. **Install Python dependencies:**
   ```powershell
   cd gui_flask
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   cd ..
   ```

   ```powershell
   cd vscode-extension
   npm install
   npm run compile

   cd ..
   ```

   ```powershell
   cd gui_flask
   ```

async function appendDebugLog(filename: string, text: string): Promise<void> {
    try {
        const baseUri = extensionContext?.globalStorageUri ?? 
                        vscode.workspace.workspaceFolders?.[0]?.uri;
        if (!baseUri) { return; }
        const dir = baseUri.fsPath;
        await fs.promises.mkdir(dir, { recursive: true });
        const filePath = path.join(dir, filename);
        const entry = `[${new Date().toISOString()}] ${text}\n`;
        await fs.promises.appendFile(filePath, entry, { encoding: 'utf8' });
    } catch {
        // best-effort only
    }
}

function stringifyUnknown(value: unknown): string {
    if (value instanceof Error) {
        return value.message;
    }
    if (typeof value === 'string') {
        return value;
    }
    if (value === undefined) {
        return '';
    }
    try {
        const json = JSON.stringify(value, null, 2);
        if (json && json !== '{}') {
            return json;
        }
    } catch {
        // Fall back below.
    }
    const text = String(value);
    return text === '[object Object]' ? 'Unknown object value' : text;
}

function extractChatResponseText(part: vscode.ChatResponsePart): string {
    if (part instanceof vscode.ChatResponseMarkdownPart) {
        return part.value.value;
    }

    const maybePart = part as unknown as { value?: unknown };
    const value = maybePart.value;
    if (typeof value === 'string') {
        return value;
    }
    if (value && typeof value === 'object' && 'value' in value) {
        const nested = (value as { value?: unknown }).value;
        if (typeof nested === 'string') {
            return nested;
        }
    }

    return '';
}

/**

 *
 * Iterates through WorkItems discovered by GoalDiscovery, sends each to the
 * MYKRO gateway for planning + fixing, then streams results into VS Code chat
 * with Keep / Discard follow-up buttons.
 *
 * The session is cancelled immediately when the user returns (IdleWatcher.onIdleEnd).
 */
import * as vscode from 'vscode';
import { GatewayClient } from './gatewayClient';
import { MykroLogger } from './logger';
import type { ChatMessage } from './types';
import type { WorkItem } from './goalDiscovery';
import { discoverGoals } from './goalDiscovery';

const CTX = 'AutonomousSession';

export type SessionState = 'idle' | 'discovering' | 'working' | 'paused';

export class AutonomousSession implements vscode.Disposable {
    private state: SessionState = 'idle';
    private abortController: AbortController | undefined;
    private sessionTimer: ReturnType<typeof setTimeout> | undefined;
    private statusBar: vscode.StatusBarItem;
    private workItems: WorkItem[] = [];
    private currentIndex = 0;
    private completedCount = 0;
    private disposables: vscode.Disposable[] = [];

    constructor(
        private readonly gatewayClient: GatewayClient,
        private readonly logger: MykroLogger,
        private readonly ensureBackend: () => Promise<void>,
    ) {
        this.statusBar = vscode.window.createStatusBarItem(
            vscode.StatusBarAlignment.Left,
            -100,
        );
        this.statusBar.command = 'mykro.toggleAutonomous';
        this.updateStatusBar();
        this.statusBar.show();
        this.logger.event(CTX, 'constructed', 
            `sessionMinutes=${this.sessionMinutes} enabled=${this.enabled}`);
    }

    private get sessionMinutes(): number {
        return vscode.workspace.getConfiguration('mykro')
            .get<number>('autonomousSessionMinutes', 30);
    }

    private get enabled(): boolean {
        return vscode.workspace.getConfiguration('mykro')
            .get<boolean>('autonomousAgentEnabled', false);
    }

    // ── Public API ──────────────────────────────────────────────────────────

    /** Start an autonomous session (called by IdleWatcher or manually). */
    async start(): Promise<void> {
        if (!this.enabled) {
            this.logger.info(CTX, 'start() skipped — autonomousAgentEnabled=false');
            return;
        }
        if (this.state === 'working' || this.state === 'discovering') {
            this.logger.trace(CTX, `start() no-op — already in state=${this.state}`);
            return; // Already running
        }

        const t0 = this.logger.enter(CTX, 'start', { resumeFrom: this.currentIndex });
        this.state = 'discovering';
        this.updateStatusBar();
        this.abortController = new AbortController();

        try {
            // Ensure gateway is available
            await this.ensureBackend();

            this.logger.info(CTX, 'discovering goals…');
            this.workItems = await discoverGoals(undefined, this.logger);
            this.currentIndex = 0;
            this.completedCount = 0;

            if (this.workItems.length === 0) {
                this.logger.info(CTX, 'no work items found — session skipped');
                this.state = 'idle';
                this.updateStatusBar();
                this.logger.exit(CTX, 'start', t0, 'no items');
                return;
            }

            this.logger.info(CTX, 
                `found ${this.workItems.length} items — starting ${this.sessionMinutes}-min session`);

            // Arm the session timeout
            this.sessionTimer = setTimeout(() => {
                this.logger.info(CTX, 'session time limit reached — stopping');
                void this.stop('timeout');
            }, this.sessionMinutes * 60_000);

            this.state = 'working';
            this.updateStatusBar();

            // Work through items
            await this.workLoop();
            this.logger.exit(CTX, 'start', t0, 
                `completed ${this.completedCount}/${this.workItems.length}`);
        } catch (err) {
            if ((err as Error)?.name === 'AbortError') {
                this.logger.trace(CTX, 'start() AbortError — session cancelled by user');
            } else {
                this.logger.exitErr(CTX, 'start', t0, err);
            }
        } finally {
            // Only reset to idle if we weren't explicitly paused
            if ((this.state as SessionState) !== 'paused') {
                this.state = 'idle';
            }
            this.updateStatusBar();
        }
    }

    /** Pause the session (user returned). Can resume later. */
    pause(): void {
        if (this.state !== 'working' && this.state !== 'discovering') {
            return;
        }
        this.logger.event(CTX, 'paused', 
            `at item ${this.currentIndex}/${this.workItems.length} — user activity detected`);
        this.abortController?.abort();
        if (this.sessionTimer) {
            clearTimeout(this.sessionTimer);
            this.sessionTimer = undefined;
        }
        this.state = 'paused';
        this.updateStatusBar();
    }

    /** Resume a paused session on next idle. */
    async resume(): Promise<void> {
        if (this.state !== 'paused' || this.currentIndex >= this.workItems.length) {
            // Nothing to resume — start fresh
            this.logger.info(CTX, 'resume() — no paused state, starting fresh');
            await this.start();
            return;
        }
        const t0 = this.logger.enter(CTX, 'resume',
            { index: this.currentIndex, total: this.workItems.length });
        this.abortController = new AbortController();
        this.sessionTimer = setTimeout(() => {
            void this.stop('timeout');
        }, this.sessionMinutes * 60_000);
        this.state = 'working';
        this.updateStatusBar();

        try {
            await this.workLoop();
            this.logger.exit(CTX, 'resume', t0, 
                `completed ${this.completedCount}/${this.workItems.length}`);
        } catch (err) {
            if ((err as Error)?.name !== 'AbortError') {
                this.logger.exitErr(CTX, 'resume', t0, err);
            } else {
                this.logger.trace(CTX, 'resume() AbortError — cancelled');
            }
        } finally {
            if ((this.state as SessionState) !== 'paused') {
                this.state = 'idle';
            }
            this.updateStatusBar();
        }
    }

    /** Stop the session completely. */
    async stop(reason: 'manual' | 'timeout' | 'done' = 'manual'): Promise<void> {
        const t0 = this.logger.enter(CTX, 'stop', 
            { reason, completed: this.completedCount, total: this.workItems.length });
        this.abortController?.abort();
        if (this.sessionTimer) {
            clearTimeout(this.sessionTimer);
            this.sessionTimer = undefined;
        }
        this.state = 'idle';
        this.updateStatusBar();
        this.logger.info(CTX,
            `session ended (${reason}): ${this.completedCount}/${this.workItems.length} items processed`);

        // Store session summary as a memory in gateway
        try {
            await fetch(
                `${(this.gatewayClient as any).baseUrl ?? 'http://127.0.0.1:8090'}/v1/memories`,
                {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({
                        text: `Autonomous session (${reason}): ${this.completedCount}/${this.workItems.length} items. ` +
                            this.workItems.slice(0, this.completedCount)
                                .map(w => w.title).join('; '),
                        category: 'autonomous_session',
                    }),
                    signal: AbortSignal.timeout(5000),
                },
            );
            this.logger.info(CTX, 'session summary written to gateway memory');
        } catch (memErr) {
            this.logger.warn(CTX, 
                `memory write skipped — ${memErr instanceof Error ? memErr.message : String(memErr)}`);
        }
        this.logger.exit(CTX, 'stop', t0);
    }

    get currentState(): SessionState {
        return this.state;
    }

    // ── Work Loop ───────────────────────────────────────────────────────────

    private async workLoop(): Promise<void> {
        while (this.currentIndex < this.workItems.length) {
            if (this.abortController?.signal.aborted) { return; }

            const item = this.workItems[this.currentIndex];
            this.updateStatusBar();
            this.logger.info(CTX,
                `[${this.currentIndex + 1}/${this.workItems.length}] processing: ` +
                `"${item.title}" source=${item.source} priority=${item.priority ?? 'n/a'}`);

            try {
                // Process this work item
                // ... implementation details ...
            } catch (err) {
                this.logger.warn(CTX, 
                    `item ${this.currentIndex}: ${err instanceof Error ? err.message : String(err)}`);
            }

            this.currentIndex++;
        }
    }

    private updateStatusBar(): void {
        const stateLabel = this.state === 'idle' ? '◯' : this.state === 'working' ? '◉' : '⊘';
        this.statusBar.text = `MYKRO ${stateLabel}`;
        this.statusBar.tooltip = `Autonomous: ${this.state}`;
    }

    dispose(): void {
        this.statusBar.dispose();
        this.disposables.forEach(d => d.dispose());
        if (this.abortController) {
            this.abortController.abort();
        }
        if (this.sessionTimer) {
            clearTimeout(this.sessionTimer);
        }
    }
}

function Test-Gateway {
    param([string]$url = "http://127.0.0.1:8090")
    try {
        $response = Invoke-WebRequest -Uri "$url/health" -TimeoutSec 5 `
                                     -UseBasicParsing -ErrorAction Stop
        if ($response.StatusCode -eq 200) {
            $data = $response.Content | ConvertFrom-Json
            return $data
        }
    } catch {
        return $null
    }
}

function Test-Model {
    param(
        [string]$port,
        [string]$name
    )
    try {
        $response = Invoke-WebRequest -Uri "http://127.0.0.1:$port/health" `
                                     -TimeoutSec 5 -UseBasicParsing -ErrorAction Stop
        if ($response.StatusCode -eq 200) {
            return $true
        }

function Start-MykroBackend {
    Write-Info "Starting MYKRO backend..."
    $scriptPath = Join-Path $PSScriptRoot "gui_flask"
    $scriptPath = Join-Path $scriptPath "start-all.ps1"
    
    if (-not (Test-Path $scriptPath)) {
        Write-Error "Could not find start-all.ps1 at: $scriptPath"
        return $false
    }

    try {
        # Launch in background
        $pwsh = (Get-Command powershell.exe -ErrorAction Stop).Source
        $arguments = "-NoProfile -ExecutionPolicy Bypass -File `"$scriptPath`" -NoGUI"
        $process = Start-Process -FilePath $pwsh -ArgumentList $arguments `
                                -WorkingDirectory $PSScriptRoot -WindowStyle Hidden -PassThru

        Write-Info "Backend process started (PID: $($process.Id))"
        Write-Info "Waiting for gateway to be ready (up to 120 seconds)..."

        # Wait for gateway
        $maxAttempts = 40  # 120s / 3s
        $attempt = 0
        while ($attempt -lt $maxAttempts) {
            $health = Test-Gateway
            if ($health) {
                Write-Success "Gateway is healthy!"
                return $true
            }
            $attempt++
            Write-Host "." -NoNewline -ForegroundColor Cyan
            Start-Sleep -Seconds 3
        }

        Write-Error "Gateway did not become healthy within 120 seconds"
        return $false
    } catch {
        Write-Error "Failed to start backend: $_"
        return $false
    }
}

function Get-VSCodeConfig {
    # Try to find VS Code settings.json in workspace
    $workspaceSettings = @(
        ".vscode/settings.json"
        "$env:APPDATA\Code\User\settings.json"
    )

    foreach ($path in $workspaceSettings) {
        if (Test-Path $path) {
            $raw = Get-Content $path -Raw
            $obj = $raw | ConvertFrom-Json
            $ht = @{}
            if ($obj -ne $null) {
                foreach ($p in $obj.PSObject.Properties) {
                    $ht[$p.Name] = $p.Value
                }
            }
            return $ht
        }
    }
    
    return @{}
}

function Update-VSCodeConfig {
    param(
        [hashtable]$updates
    )
    
    # Try workspace settings first
    $settingsPath = ".vscode/settings.json"
    
    if (-not (Test-Path ".vscode")) {
        New-Item -ItemType Directory -Path ".vscode" -Force | Out-Null
    }

    if (Test-Path $settingsPath) {
        $raw = Get-Content $settingsPath -Raw
        $obj = $raw | ConvertFrom-Json
        $config = @{}
        if ($obj -ne $null) {
            foreach ($p in $obj.PSObject.Properties) {
                $config[$p.Name] = $p.Value
            }
        }
    } else {
        $config = @{}
    }

    # Merge updates
    foreach ($key in $updates.Keys) {
        $config[$key] = $updates[$key]
